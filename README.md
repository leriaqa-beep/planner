# Ежедневник

Недельный планировщик задач: отметки выполненного, перенос на завтра, редактирование и печать чек-листов на день или неделю (A4).

Откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → Branch: `main`, папка `/root`).

Задачи хранятся в браузере (localStorage), поэтому на каждом устройстве список свой.

## Бэкапы

Внизу страницы, блок «Резервная копия»:
- **Скачать бэкап** сохраняет все задачи в файл `.json`.
- **Восстановить из файла** загружает задачи из бэкапа: можно добавить их к текущим или заменить всё.

Через бэкап удобно переносить задачи между устройствами.
