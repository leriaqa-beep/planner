# Ежедневник

Недельный планировщик задач: отметки выполненного, перенос на завтра, редактирование и печать чек-листов на день или неделю (A4).

Откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → Branch: `main`, папка `/root`).

Задачи хранятся в браузере (localStorage), поэтому на каждом устройстве список свой.

## Возможности

- **Главное на день**: звёздочка ☆ отмечает до трёх ключевых задач, они показываются наверху дня и печатаются в чек-листе.
- **Жду ответа**: задача откладывается до даты следующего контакта и сама появляется в этот день. Список ожиданий виден на сегодняшнем дне.
- **Время недели**: сколько часов доступно, запланировано и свободно, и сколько ушло на каждое направление.
- **Пересечения**: задачи, которые накладываются по времени или выходят за рабочие часы, подсвечиваются.
- **Переносы с причиной**: при переносе выбирается причина, а за неделю видно, сколько было переносов и почему.

## Бэкапы

Внизу страницы, блок «Резервная копия»:
- **Скачать бэкап** сохраняет все задачи в файл `.json`.
- **Восстановить из файла** загружает задачи из бэкапа: можно добавить их к текущим или заменить всё.

Через бэкап удобно переносить задачи между устройствами.
